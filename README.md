Solmar Heat — a top-down 2D open-world crime game set in Solmar Bay. Steal cars, outrun the police across a 1–5 star wanted system, take taxi fares, and run three story missions as Jax Marlowe. Vanilla JavaScript + Canvas 2D, no libraries, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
